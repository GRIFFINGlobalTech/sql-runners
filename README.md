# SQL Runners

Daily HackerRank SQL practice: **6 questions a day — 2 Easy, 2 Medium, 2 Hard.**

## Structure

```
SQLRunners/
├── 2026-10-13/                  one folder per day, at the root
│   ├── README.md                index for the day
│   ├── 01-easy-<slug>.md
│   ├── 02-easy-<slug>.md
│   ├── 03-medium-<slug>.md
│   ├── 04-medium-<slug>.md
│   ├── 05-hard-<slug>.md
│   └── 06-hard-<slug>.md
├── 2026-10-14/
├── scripts/new-day.ps1          scaffolds a new day folder
├── scripts/build-index.ps1      regenerates the day READMEs + the log below
└── templates/question.md        template every question file starts from
```

Every question file contains: link to the question, difficulty, intuition, solution walkthrough, and the SQL query.

## Daily workflow

```powershell
# 1. Scaffold today: pass the 6 HackerRank links/slugs in order (easy, easy, medium, medium, hard, hard)
.\scripts\new-day.ps1 -Questions the-blunder, japanese-cities-attributes, binary-search-tree-1, `
    new-companies, challenges, contest-leaderboard

# 2. Solve them and fill in Problem / Intuition / Walkthrough / SQL (+ Notes if a submission failed).
#    Set each Status row to Passed or Failed (new files start as Pending).

# 3. Refresh the indexes, then commit to main
.\scripts\build-index.ps1
git add <today> README.md
git commit -m "day N"
git push
```

## Branching

Everything lives on `main`. Use `new-day.ps1 -Branch` only when a day needs a pull request for review.
